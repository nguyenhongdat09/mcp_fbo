**FastBusiness XML - Quick Reference for AI Autocomplete**

**🎯 Mục đích tài liệu**

Tài liệu này tổng hợp **các pattern chung** trong tất cả file XML của
FastBusiness để AI có thể:

-   ✅ Nhận diện nhanh loại file (Dir, Grid, Filter)

-   ✅ Detect ngôn ngữ đang code (SQL, JavaScript, XML)

-   ✅ Suggest code đúng theo context

-   ✅ Hiểu partition strategy và result structure

**1. File Type Detection**

**Quick Detection Rules**

\<!\-- FILTER XML \--\>

\<dir type=\"Report\" cache=\"true\"\>

\<!ENTITY XMLWhenFilterLoading \...\>

\<command event=\"Processing\"\>

\<!\-- DIR XML (Form/Category) \--\>

\<dir type=\"Voucher\"\>

\<command event=\"Inserting\"\>

\<command event=\"Updating\"\>

\<!\-- GRID VIEW XML \--\>

\<grid type=\"Voucher\"\>

\<queries\>

\<query event=\"Loading\"\>

\<toolbar\>

\<!\-- GRID DETAIL XML \--\>

\<grid type=\"Detail\"\>

\<!\-- Embedded in Dir \--\>

\<!\-- No toolbar \--\>

**Detection Priority**

1\. Check \<dir type=\"Report\"\> → FILTER

2\. Check \<grid type=\"Detail\"\> → GRID DETAIL

3\. Check \<grid\> + \<queries\> + \<toolbar\> → GRID VIEW

4\. Check \<dir type=\"Voucher\"\> → DIR

**2. Language Detection in XML**

**CDATA Blocks**

\<!\-- SQL in commands \--\>

\<command event=\"Inserting\"\>

\<text\>

\<\![CDATA\[

declare \@variable varchar(32)

select \@variable = \...

\]\]\>

\</text\>

\</command\>

\<!\-- JavaScript in script \--\>

\<script\>

\<text\>

\<\![CDATA\[

function init\$Form(f) {

var value = f.getItemValue(\'field\');

}

\]\]\>

\</text\>

\</script\>

\<!\-- SQL in response/action \--\>

\<action id=\"GetData\"\>

\<text\>

\<\![CDATA\[

select \* from dmkh where ma_kh = \@ma_kh

\]\]\>

\</text\>

\</action\>

**Detection Keywords**

**SQL indicators:**

-   declare, select, insert, update, delete

-   exec, begin, end, if, while

-   \@variable, @@userID, @@language

**JavaScript indicators:**

-   function, var, const, let

-   if, for, while, return

-   .getItemValue, .setItemValue, sender, e.type

**3. Common XML Structure Patterns**

**Fields Definition (ALL FILE TYPES)**

\<fields\>

\<!\-- Text field \--\>

\<field name=\"ma_kh\"\>

\<header v=\"Mã khách hàng\" e=\"Customer Code\"/\>

\</field\>

\<!\-- Date field \--\>

\<field name=\"ngay_ct\" type=\"DateTime\"

dataFormatString=\"@datetimeFormat\"

allowNulls=\"false\"

defaultValue=\"new Date()\"\>

\<header v=\"Ngày CT\" e=\"Date\"/\>

\</field\>

\<!\-- Lookup field (ALWAYS có field companion) \--\>

\<field name=\"ma_kh\"\>

\<items style=\"AutoComplete\"

controller=\"Customer\"

reference=\"ten_kh%l\"/\>

\</field\>

\<field name=\"ten_kh%l\" external=\"true\" readOnly=\"true\"\>

\<header v=\"\" e=\"\"/\>

\</field\>

\<!\-- Dropdown \--\>

\<field name=\"status\" clientDefault=\"1\"\>

\<items style=\"DropDownList\"\>

\<item value=\"1\"\>\<text v=\"Chờ duyệt\" e=\"Open\"/\>\</item\>

\<item value=\"2\"\>\<text v=\"Đã duyệt\" e=\"Approved\"/\>\</item\>

\</items\>

\</field\>

\<!\-- Grid Detail reference (DIR only) \--\>

\<field name=\"d91\" external=\"true\" rows=\"144\"\>

\<items style=\"Grid\" controller=\"PRDetail\" row=\"1\"\>

\<item value=\"ForeignKey\"\>

\<text v=\"String: stt_rec, stt_rec\"/\>

\</item\>

\</items\>

\</field\>

\</fields\>

**Common Attributes:**

-   allowNulls=\"false\" = Required

-   readOnly=\"true\" = Not editable

-   hidden=\"true\" = Not displayed

-   external=\"true\" = Not in DB (computed)

-   clientDefault=\"value\" = Default value

-   inactivate=\"true\" = Readonly when editing

**4. Partition Strategy (CRITICAL)**

**Table Naming**

Structure: d91\$000000

Data: d91\$202501 (January 2025)

d91\$202502 (February 2025)

**Placeholders in SQL**

\-- ALWAYS use placeholders, NEVER hardcode

@@partition\$current \-- 202501 (new period)

@@partition\$previous \-- 202412 (old period)

@@master \-- m91\$202501

@@prime\$partition\$current \-- d91\$202501

@@prime\$partition\$previous \-- d91\$202412

@@inquiry\$partition\$current \-- i91\$202501

**Common Patterns**

**Insert:**

insert into @@prime\$partition\$current

select \* from \@d91

**Update (same month):**

update @@prime\$partition\$current

set so_luong = \@so_luong

where stt_rec = \@stt_rec

**Update (cross-month):**

\-- Delete from old partition

delete @@prime\$partition\$previous

where stt_rec = \@stt_rec

\-- Insert to new partition

insert into @@prime\$partition\$current

select \* from \@d91

**Query multiple months:**

exec FastBusiness\$Partition\$Execute

\'select \* from d91\$%Partition where %\[ngay_ct between \@from and
\@to\]%\',

null, \'ngay_ct\', \@from, \@to, @@userID, @@admin

**5. SQL Result Structure (CRITICAL)**

**Result Access Pattern**

// SQL returns columns in ORDER

// JavaScript accesses via result\[index\].Value

// SQL:

select ma_kh, ten_kh, dia_chi from dmkh

// JavaScript:

var maKH = result\[0\].Value; // ma_kh (column 1)

var tenKH = result\[1\].Value; // ten_kh (column 2)

var diaChi = result\[2\].Value; // dia_chi (column 3)

// NOT:

// var maKH = result\[0\].ma_kh; ❌ WRONG!

**Common Response Pattern**

\<action id=\"GetCustomer\"\>

\<text\>

\<\![CDATA\[

select ma_kh, ten_kh, dia_chi, dien_thoai

from dmkh

where ma_kh = \@ma_kh

\]\]\>

\</text\>

\</action\>

function on\$ResponseComplete(sender, e) {

if (e.type.Context == \'GetCustomer\') {

var result = e.type.Result;

// Access by index

var maKH = result\[0\].Value;

var tenKH = result\[1\].Value;

var diaChi = result\[2\].Value;

var dienThoai = result\[3\].Value;

}

}

**6. Common JavaScript Patterns**

**Object Variables**

// DIR (Form)

var f = sender; // Form object

f.getItemValue(\'field_name\') // Get value

f.setItemValue(\'field\', value) // Set value

f.getItem(\'field\') // Get field object

// GRID VIEW

var g = sender; // Grid object

g.\_getItemValue(row, col) // Get cell value

g.\_setItemValue(row, col, value) // Set cell value

g.\_rowCount // Number of rows

g.\_activeRow // Current row

// GRID DETAIL

var g = sender; // Grid object

var f = g.get_element().parentForm // Parent form!

g.\$a = { /\* expressions \*/ } // Calculation dictionary

**Lifecycle Functions**

**DIR:**

function init\$Form\$(f) { }

function active\$Form\$(f) { }

function close\$Form\$(f) { }

**GRID VIEW:**

function load\$Grid(g) { }

function scattering\$Grid(g) { }

function dispose\$Grid(g) { }

**GRID DETAIL:**

function load\$GridVoucherDetail\$(g) { }

function dispose\$GridVoucherDetail\$(g) { }

**FILTER:**

function active\$VoucherFilter\$(sender) { }

function close\$VoucherFilter\$(sender) { }

**Event Handlers**

// Response from AJAX

function on\$Form\$ResponseComplete(sender, e) {

var f = e.object;

var context = e.type.Context;

var result = e.type.Result;

switch(context) {

case \'ActionName\':

var value = result\[0\].Value;

break;

}

}

// Command execution (toolbar/button)

function on\$Form\$ExecuteCommand(sender, e) {

var action = e.type.Action;

switch(action) {

case \'Save\':

// Handle save

break;

}

}

**7. Common SQL Patterns**

**Variable Declaration**

declare \@variable varchar(32)

declare \@ngay_ct smalldatetime

declare \@so_luong numeric(18,2)

\-- System variables (always available)

@@userID \-- Current user ID

@@admin \-- Is admin (bit)

@@language \-- \'V\' or \'E\'

@@unit \-- Current unit code

@@id \-- Form/Grid ID

**Conditional Logic**

\-- Preprocessor directives

#IF @@action = \'New\' #THEN

\-- Code for new record

#ELSE

\-- Code for edit

#END

#IF \$field.NewValue \<\> \$field.OldValue #THEN

\-- Field value changed

#END

**Standard Checks**

\-- Check exists

if exists(select 1 from dmkh where ma_kh = \@ma_kh) begin

\-- Handle exists

end

\-- Not exists

if not exists(select 1 from dmkh where ma_kh = \@ma_kh) begin

\-- Handle not exists

select \'ma_kh\' as field, N\'Khách hàng không tồn tại\' as message

return

end

\-- Authorization check

if @@admin \<\> 1 and not exists(

select 1 from sysunitrights

where user_id = @@userID and ma_dvcs = @@unit

) begin

select \'\$NotAuthorized\' as message

return

end

**Insert/Update/Delete Patterns**

\-- Insert with partition

insert into @@prime\$partition\$current (stt_rec, ngay_ct, \...)

values (@stt_rec, \@ngay_ct, \...)

\-- Update with partition

update @@prime\$partition\$current

set status = \@status, datetime2 = getdate()

where stt_rec = \@stt_rec

\-- Delete with partition

delete @@prime\$partition\$previous

where stt_rec = \@stt_rec

**GRID DETAIL - JavaScript**

function load\$GridVoucherDetail\$(g) {

var f = g.get_element().parentForm; // Access parent!

// Calculation expressions

g.\$a = {

// Basic calculations

tien: \'\[tien\]:=\[so_luong\]\*\[gia\]\',

// With parent variable (\$)

gia: \'\[gia\]:=\[gia_nt\]\*\[\$ty_gia\]\',

// Aggregate to form

t_tien: \[\'t_tien\', \'tien\'\]

};

// Request parameters (include parent fields)

g.\$h = \[\'ngay_ct\', \'ma_nt\', \'ty_gia\', \'stt_rec\'\];

g.add_itemValueChanged(onChange\$GridVoucherDetail\$);

}

function onChange\$GridVoucherDetail\$(sender, e) {

var o = e.get_object();

var g = o.grid;

switch(o.field.Name) {

case \'so_luong\':

// Calculate and aggregate

g.validExpression(o, \[

g.\$a.tien // Calculate

\], \[

g.\$a.t_tien // Aggregate to form

\]);

break;

}

}

**9. AI Suggestion Rules**

**When Detecting SQL in CDATA**

**If in DIR/FILTER command:**

\-- Suggest partition-aware code

insert into @@prime\$partition\$current

select \* from \@d91

\-- Suggest validation

if not exists(select 1 from dmkh where ma_kh = \@ma_kh) begin

select \'ma_kh\' as field, N\'Error message\' as message

return

end

**If in GRID query:**

\-- Suggest SP call

exec FastBusiness\$App\$Voucher\$Loading

@@id, @@master, @@pageIndex, @@pageCount, \...

**If in response/action:**

\-- Suggest simple query with return

select ma_kh, ten_kh, dia_chi

from dmkh

where ma_kh = \@ma_kh

return

**When Detecting JavaScript in CDATA**

**If in DIR script:**

// Suggest form patterns

function active\$Form\$(f) {

f.add_onResponseComplete(on\$Form\$ResponseComplete);

}

function on\$Form\$ResponseComplete(sender, e) {

if (e.type.Context == \'ActionName\') {

var result = e.type.Result;

var value = result\[0\].Value; // By index!

}

}

**If in GRID VIEW script:**

// Suggest grid patterns

function load\$Grid(g) {

g.\_\$k = \[\]; // Selection array

g.add_commandEvent(on\$Grid\$ExecuteCommand);

}

// Access by index

var value = g.\_getItemValue(row, col);

**If in GRID DETAIL script:**

// Suggest with parent access

function load\$GridVoucherDetail\$(g) {

var f = g.get_element().parentForm;

g.\$a = {

tien: \'\[tien\]:=\[so_luong\]\*\[gia\]\',

t_tien: \[\'t_tien\', \'tien\'\]

};

}

// Parent variable with \$

\'\[gia\]:=\[gia_nt\]\*\[\$ty_gia\]\'

**If in FILTER script:**

// Suggest filter patterns

function active\$VoucherFilter\$(sender) {

sender.add_validation(function(f) {

var from = f.getItemValue(\'ngay_tu\');

var to = f.getItemValue(\'ngay_den\');

if (from \> to) {

alert(\'Invalid date range\');

return false;

}

return true;

});

}

**10. Common Mistakes to Avoid**

**❌ WRONG Patterns**

// WRONG: Access result by property name

var maKH = result\[0\].ma_kh; // ❌ NO!

// WRONG: Hardcode partition

select \* from d91\$202501 // ❌ NO!

// WRONG: Grid Detail without parent access

var ty_gia = g.getItemValue(\'ty_gia\'); // ❌ Not in grid!

// WRONG: Quote search results

var text = result\[0\].Value;

alert(\"The value is: \" + result\[0\].Value); // ❌ Don\'t quote
sources

**✅ CORRECT Patterns**

// CORRECT: Access result by index

var maKH = result\[0\].Value; // ✅ YES!

// CORRECT: Use partition placeholder

select \* from @@prime\$partition\$current // ✅ YES!

// CORRECT: Access parent form

var f = g.get_element().parentForm;

var ty_gia = f.getItemValue(\'ty_gia\'); // ✅ YES!

// CORRECT: Paraphrase, never quote

var text = result\[0\].Value;

// Process text without quoting original source

**11. Quick Cheat Sheet**

**Detection Checklist**

✓ Check root element: \<dir\> or \<grid\>

✓ Check type attribute: Report, Voucher, Detail

✓ Check for \<queries\> → Grid View

✓ Check for cache=\"true\" → Filter

✓ Check for parentForm → Grid Detail

✓ Check for Processing command → Filter

**Language Detection**

✓ Inside \<\![CDATA\[\...\]\]\>

✓ Parent tag: \<command\> → SQL

✓ Parent tag: \<script\> → JavaScript

✓ Parent tag: \<action\> → SQL

✓ Keywords: declare/select → SQL

✓ Keywords: function/var → JavaScript

**Partition Detection**

✓ Look for: \$\$partition\$current

✓ Look for: \$\$partition\$previous

✓ Look for: \$YYYYMM pattern

✓ Look for: \<partition field=\"ngay_ct\"\>

**Result Access**

✓ ALWAYS: result\[index\].Value

✓ NEVER: result\[0\].property_name

✓ Index = column position in SELECT

**12. Priority Rules for AI**

**When Suggesting Code:**

1.  **Detect file type first** (Filter \> Grid Detail \> Grid View \>
    Dir)

2.  **Detect language** (SQL vs JavaScript vs XML)

3.  **Check for partition** (use placeholders if yes)

4.  **Check parent dependency** (Grid Detail needs parentForm)

5.  **Use result\[\].Value** (never result\[\].property)

6.  **Follow lifecycle patterns** (init\$, load\$, active\$, dispose\$)

7.  **Never quote copyrighted content** (paraphrase always)

**Confidence Levels:**

-   **High confidence**: Pattern matches 80%+ indicators

-   **Medium confidence**: Pattern matches 50-80%

-   **Low confidence**: Ask user for clarification

**Fallback Strategy:**

If uncertain about file type:

→ Suggest generic XML pattern

If uncertain about language:

→ Check parent tag (command/script/action)

If uncertain about partition:

→ Safe to assume yes (common pattern)

If uncertain about result structure:

→ ALWAYS use result\[index\].Value pattern

**📝 Summary**

**3 Golden Rules:**

1.  **Partition**: Always use @@partition\$current/previous, never
    hardcode

2.  **Result Access**: Always result\[index\].Value, never property
    names

3.  **Parent Access**: Grid Detail needs g.get_element().parentForm

**File Type Priority:**

Filter → Grid Detail → Grid View → Dir

**Language Detection:**

\<command\> → SQL

\<script\> → JavaScript

\<action\> → SQL

**When in doubt:**

-   Use partition placeholders

-   Use result\[\].Value pattern

-   Check for parentForm in Grid Detail

-   Follow lifecycle function naming

This quick reference covers 90% of patterns in FastBusiness XML. For
edge cases, refer to full documentation of specific file types.
