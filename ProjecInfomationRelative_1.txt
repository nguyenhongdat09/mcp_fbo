SECTION 1: FILE TYPE DETECTION (CRITICAL - Always Check First!)

═══════════════════════════════════════════════════════════════════════════

\--\>

\<!\--

DETECTION ALGORITHM (Priority Order):

1\. Check \<dir type=\"Report\"\> + \<!ENTITY XMLWhenFilterLoading\> →
FILTER XML

2\. Check \<grid type=\"Detail\"\> without \<toolbar\> → GRID DETAIL XML

3\. Check \<grid\> + \<queries\> + \<toolbar\> → GRID VIEW XML

4\. Check \<dir type=\"Voucher\|Category\"\> → DIR FORM XML

FILE TYPE 1: FILTER XML

Signature:

\<dir type=\"Report\" cache=\"true\"\>

\<!ENTITY XMLWhenFilterLoading SYSTEM \"\...\"\>

\<command event=\"Processing\"\>

Purpose: Báo cáo có điều kiện lọc

Key Events: Processing (execute report)

FILE TYPE 2: DIR XML (Form)

Signature:

\<dir type=\"Voucher\"\> or \<dir type=\"Category\"\>

\<command event=\"Inserting\"\>

\<command event=\"Updating\"\>

Purpose: Form nhập liệu chứng từ/danh mục

Key Events: Inserting, Updating, Deleting

FILE TYPE 3: GRID VIEW XML

Signature:

\<grid type=\"Voucher\"\> or \<grid type=\"Category\"\>

\<queries\>\<query event=\"Loading\"\>

\<toolbar\> (full toolbar)

Purpose: Danh sách chứng từ/danh mục với pagination

Key Events: Loading, Finding

FILE TYPE 4: GRID DETAIL XML

Signature:

\<grid type=\"Detail\"\>

NO \<toolbar\> element

Embedded in \<dir\>

Purpose: Chi tiết trong Form

Key Feature: MUST access parentForm

SECTION 3: PARTITION STRATEGY (CRITICAL!)

═══════════════════════════════════════════════════════════════════════════

\--\>

\<!\--

TABLE STRUCTURE:

Template: d91\$000000

Data: d91\$202501 (Jan 2025), d91\$202502 (Feb 2025)

PLACEHOLDERS (ALWAYS USE):

@@partition\$current → 202501

@@partition\$previous → 202412

@@master → m91\$202501

@@prime\$partition\$current → d91\$202501

@@prime\$partition\$previous → d91\$202412

PATTERNS:

\-- Insert new

insert into @@prime\$partition\$current select \* from \@d91

\-- Update same month

update @@prime\$partition\$current set so_luong = \@so_luong

where stt_rec = \@stt_rec

\-- Update cross-month (date changed)

delete @@prime\$partition\$previous where stt_rec = \@stt_rec

insert into @@prime\$partition\$current select \* from \@d91

\-- Query multiple months

exec FastBusiness\$Partition\$Execute

\'select \* from d91\$%Partition where %\[ngay_ct between \@from and
\@to\]%\',

null, \'ngay_ct\', \@from, \@to, @@userID, @@admin

RULES:

❌ NEVER: select \* from d91\$202501

✅ ALWAYS: select \* from @@prime\$partition\$current

function on\$Form\$ResponseComplete(sender, e) {

var maKH = result\[0\].Value; // ma_kh

var tenKH = result\[1\].Value; // ten_kh

var diaChi = result\[2\].Value; // dia_chi

// ❌ WRONG - Doesn\'t work!

\<!\--

FORM METHODS (f = form object):

// Get/Set Values

f.getItem(name) → Get field object

f.getItem(name).value → Get/set text

f.getItemValue(name) → Get number/date

f.setItemValue(name, value) → Set any value

// Form State

f.\_action → \'New\'/\'Edit\'/\'View\'

f.\_fields → All fields array

f.\_fields.length → Field count

// Validation

f.validFields(\'field1, field2\') → Validate

f.setReadOnlyFields(\'field1\') → Make readonly

// Focus

f.live(o) → Focus to object

f.getItem(name).focus() → Focus to field

// Tabs

f.\_tabContainer.\_activeTabIndex → Current tab

f.\_tabContainer.set_activeTabIndex(i) → Set tab

// Buttons

f.\_findButton(\'Save\') → Get button

// Request

f.request(\'ActionID\', \'Context\', \[\'param1\'\], o)

// Grid Detail

f.grid → Get detail grid

LIFECYCLE:

function init\$Form(f) { } → Initialization

function active\$Form(f) { } → Activated

function close\$Form(f) { } → Closing
