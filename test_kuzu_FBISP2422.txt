  - mode=query (mac dinh): chay cypher_query nhu cu.
  - mode=schema: doc schema live tu Kuzu va tra:
      + tables XmlFile / Rel
      + ten + type tat ca columns
      + giai thich cac edge_type FBO
      + rule viet Kuzu Cypher
      + query mau GRID / RETRIEVE / chuoi 2 cap

  Vi du MCP arguments:
    {
      "mode": "schema",
      "cypher_query": "",
      "reference_file": "<duong dan file XML trong project>"
    }

  Agent nen goi mode=schema khi chua biet columns / edge_type, sau do moi goi:
    {
      "mode": "query",
      "cypher_query": "MATCH ... LIMIT 20",
      "reference_file": "<duong dan file XML trong project>"
